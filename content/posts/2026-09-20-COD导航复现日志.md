## 与北极熊2025比

| 项目 | 北极熊 `pb2025_sentry_nav` | COD `COD_RM2026_Navigation` |
|---|---|---|
| 定位/里程计 | Point-LIO + **small_gicp 全局重定位** | small_point_lio，偏 **纯 LIO** |
| 先验地图 | `.pgm/.yaml + .pcd` | 主要 `.pgm/.yaml` |
| SLAM | Point-LIO + terrain + LaserScan + Nav2 建图流程 | Point-LIO + `slam_toolbox` |
| `map→odom` | 导航时由重定位体系维护；SLAM 时静态处理 | SLAM 场景直接静态 `map→odom=0` |
| 全局规划 | Nav2 默认 Global Planner | Nav2 |
| 局部控制 | 自研 `pb_omni_pid_pursuit_controller` | **MPPI** 为主 |
| 障碍物 | 3D terrain analysis，近远场分离 | 点云裁剪 + pointcloud→LaserScan，整体更简单 |
| 全向底盘 | 专门做了 omni pursuit controller | MPPI + 参数调节 |
| TF | 很强调 TF、雷达原点/底盘原点关系 | 明确奉行 KISS，甚至建议静态 TF 比 URDF 简单 |
| 仿真 | **配套完整 Gazebo RM 仿真器** | loopback sim 主要偏决策测试 |
| Sim2Real | 核心卖点之一 | 有实车，但不是整个项目最大特色 |
| 多机器人 | namespace 从架构层考虑 | 没有把这个作为重点 |
| 航点 | 基本 Nav2 Goal | **CSV 多航点 + waypoint editor** |
| 决策 | 导航仓库本身不是重点 | **BehaviorTree.CPP + behavior.ros2 + Groot2** |
| 工程复杂度 | 高 | 相对低 |
| 比赛针对性 | 通用 RM 哨兵框架 | **RMUL2026 专项明显** |

## 安装准备

先按github上进行克隆与编译：https://gitee.com/codnavgation/cod_-rm2026_-navigation

再把这个仓库里的功能包克隆到src文件夹里：https://github.com/qza36/COD_loopback_sim

## 运行

### 仿真

先修改掉`nav2_loopback_sim/params/nav2_params.yaml`里的`yaml_filename`。
这个也会被launch覆盖。
