## 第 1 页：NWM：用未来画面评价导航路线

**建议用时：约 1 分钟**

**对应文件：NWM 组会汇报（讲解增强版），共 5 页。** 正文可直接用于练习；括号中的“指图”是讲解动作提示。每页末尾折叠的备讲内容用于理解和问答，不必逐项朗读。全稿主讲约 9 分钟。

### 口述稿

上次主要介绍了世界模型是什么，这次看它怎样参与导航。先从这张图开始，按从左到右的顺序读。

（指左侧两张 Input）上下两行从相同的观测出发，黄色线条表示两种不同的候选走法。这里输入模型的是画面和动作，黄色线只是为了把动作路线直观地画出来。

（指中间两行画面）每一行是在对应动作下连续预测的未来。标着 `gen.` 的都是模型生成的画面，不是机器人已经走过去以后拍到的照片；从左往右是后续预测时刻。两行的结果不同，是因为它们使用了不同的动作序列。

（指右侧 Goal 和两个 Score）右侧垃圾桶的照片是目标。把每条路线最后预测的画面与这张目标照片比较，就可以给两种走法评分。上下两个 Score 框分别对应上下两条路线；这一张示意图只画了评分入口，没有给出具体分数，第三页会展示真实的评分数字。

所以，这张图展示了“输入候选动作、生成未来、与目标比较”的完整关系。GNM、NoMaD 主要负责生成路线，NWM 则可以用预测结果帮助评价这些路线。

## 第 2 页：NWM 如何预测机器人眼前的未来？

**建议用时：约 2 分钟**

### 口述稿

这张图是 CDiT 的一个计算块，主干从底部往顶部走。VAE 的编码器和解码器没有画在这张图里：历史图像先被 VAE 编成内部表示，预测完成以后，再由解码器还原成图像。

（指底部 Future State）底部是要预测的未来表示，记作 `s_{τ+1}`。这是扩散模型：训练时给真实未来表示加噪声，让模型学习恢复；生成时从噪声开始预测，所以并不需要提前知道真实未来。

（沿主干指橙色 Self-Attention）第一个主要模块是自注意力。它让待预测帧内部的不同图像块交换信息，协调同一幅未来画面的内容。这里的自注意力只处理当前待预测帧，不把所有历史帧都放进去两两计算。

（指右侧 Context States，再指粉色 Cross-Attention）历史画面通过交叉注意力进入。可以理解成：当前帧提出查询，去历史画面中查找相关信息。图中虚线 `K,V` 就是历史帧提供的参考内容。这样，模型可以利用之前见过的场景来约束未来预测。

（指绿色 Pointwise Feedforward）上面的前馈网络继续处理每个图像块的特征。旁边的回绕箭头和加号表示把处理前的信息与新结果相加，保留原有信息并逐步更新。

（指右下方 Conditioning → Embedding → AdaLN）另一路输入是动作和时间条件。平面位移、朝向变化、预测时间间隔，以及扩散去噪步先变成向量，再产生图中的缩放、偏移等系数，调节主干的计算。因此，同一张起始画面输入不同动作，能够得到不同预测。

图上 `×N` 表示这样的块堆叠多层，并不表示一次生成 N 帧。完成一帧预测后，再结合下一个动作调用模型，才形成前一页看到的连续未来画面。

<details>
<summary><strong>备讲：图中标注与可能的追问</strong></summary>

### 图中模块与符号备讲

| 标注 | 通俗解释与对应关系 |
|---|---|
| `Future State s_{τ+1}` | 待预测的未来图像表示；主干围绕它进行去噪处理 |
| `Context States` | 当前及历史观测经过编码后的表示，不是目标照片 |
| `Multi-Head Self-Attention` | 多头自注意力：在当前待预测帧内部交换信息 |
| `Multi-Head Cross-Attention` | 多头交叉注意力：当前帧读取历史帧的信息 |
| `K,V` | Key / Value（键 / 值），来自历史表示；对应的 Query（查询）来自当前预测帧 |
| `Pointwise Feedforward` | 逐位置前馈网络，进一步变换每个 Token（图像块词元）的特征 |
| `Layer Norm` | Layer Normalization（层归一化），调整特征的数值尺度；不负责生成路线 |
| `Scale, Shift` | 根据条件对特征缩放和偏移；图中 `γ、β` 对应这类调节系数 |
| `Scale` 与 `α₁、α₂、α₃` | 调节各处理分支输出的幅度，然后通过加号与主干信息合并 |
| `Embedding` | 把动作及时间等数值编码成网络可使用的向量 |
| `AdaLN` | Adaptive Layer Normalization（自适应层归一化），根据条件产生用于调节主干的系数 |
| `u、φ` | 平面位移与偏航变化，描述怎样移动、怎样改变朝向 |
| `k` 与 `t` | `k` 是物理时间偏移，`t` 是扩散去噪步；它们不是同一个时间量 |
| 回绕箭头与 `+` | Residual Connection（残差连接），把分支结果加回主干 |
| `CDiT Block ×N` | 多个计算块堆叠形成网络深度；与生成帧数、扩散去噪步数都不同 |

**与第四页的联系：** 由于历史帧主要通过交叉注意力被读取，模型避免了把全部历史词元一起做全局自注意力。这是论文比较计算效率时的重要结构原因。

</details>

资料来源：[论文 Figure 2：CDiT Block](https://arxiv.org/html/2412.03572v2#S3.F2)。

## 第 3 页：预测结果怎样用于选路？

**建议用时：约 1 分 30 秒**

### 口述稿

这一张可以看成第一页评分示意的具体版本。先从左侧读：Observation 是当前观测，Goal 是目标图像，它们是本次选路的已知条件。

（指中间轨迹图）中间的 P1、P2、P3 是三条候选路线，对应橙、红、绿三种颜色。横纵轴是平面位置，标注单位为米；蓝色 Goal 表示目标参考，不是第四条候选。曲线表示不同的移动方式，颜色只是帮助我们把路线和右侧结果对应起来。

（逐一指右侧 Prediction 1、2、3）右侧每张图都是模型沿对应候选路线预测的最后一张画面。P1 对应 Prediction 1，P2 对应 Prediction 2，P3 对应 Prediction 3。这里是在比较三条路线各自的终点预测，不是把右侧三张图按顺序接成一段视频。

（指三个 Loss）每张预测末帧都与左侧同一张 Goal 图像计算 LPIPS。它比较图像特征的差异，而不是直接计算路线终点的几何距离。P1 是零点四八四，P2 是零点五零八，P3 是零点三六九，所以选择 P3。绿色框里的 Min 指感知代价最小，不代表成功率，也不代表零误差。

这一图展示的是外部策略排序：NoMaD 提供候选，NWM 预测和评分。模型选择时使用目标图像，不需要真实未来轨迹；真实轨迹是在后面的离线实验中用于检验结果。

## 第 4 页：相比已有方法，具体提升在哪里？

**建议用时：约 2 分 30 秒**

**本页关键数字：** ATE 1.93 降至 1.13（降低 41.5%）；RPE 0.52 降至 0.35（降低 32.7%）。

### 口述：先读导航误差表

这一页有两类证据，先读导航结果，再看预测模型的计算效率。

（指表头）表格评估的是 RECON 已知环境里的两秒轨迹。ATE 衡量整条轨迹与真实轨迹的偏差，RPE 衡量相邻位姿变化的误差，两个向下箭头都表示越小越好。数值写成均值加减标准差，表示重复评估的平均水平和波动，不是一次实验的最大值与最小值。

（从上往下指五行）第一行 GNM 是已有导航策略；第二行 NoMaD 也是策略基线。第三、四行都保留 NoMaD 生成路线，分别生成十六条和三十二条候选，再让 NWM 筛选；这里的“乘十六、乘三十二”指候选数量。最后一行才是 NWM 自己搜索路线，不依赖 NoMaD 提供候选。

（指 NoMaD 与最后一行）ATE 从一点九三降到一点一三，RPE 从零点五二降到零点三五，按均值计算下降约百分之四十一点五和百分之三十二点七。再看两行排序结果，也比 NoMaD 的误差低，说明它还可以辅助已有策略。这里比较的是轨迹误差，不能换算成实机成功率。

### 口述：再读计算效率气泡图

（指横纵轴和图例）横轴是 TFLOPs，也就是运算量，越靠左越省计算；纵轴是 LPIPS，越靠下表示未来图像预测误差越小。注意，这里的 LPIPS 是预测图像与真实未来图像比较，和第三页拿预测末帧与目标照片做比较，是不同的实验用途。

蓝色圆代表 CDiT，红色圆代表标准 DiT；每个圆是一种模型配置。圆大小表示参数量，S、B、L、XL 表示各自系列中从小到大的模型，不同架构的同名档位不能直接当作参数量完全相同。

（指蓝色 CDiT-L 与红色 DiT-XL）这两个圆大小接近，可以观察相近参数规模的对比：蓝色圆更靠左，也更靠下，说明计算量更少，同时预测误差更低。论文报告的约四倍 FLOPs 优势，就是在这样的可比规模下讨论的，不能理解成每种配置、每块硬件或整套导航都快四倍。

## 第 5 页：NWM 怎样按指定要求规划路线？

**建议用时：约 1 分 30 秒**

### 口述稿

这一页看一个具体的动作约束实验：除了接近目标，还要求路线先向左或右运动，再向前。

（指两张照片）左边的 Condition Image 是当前观测，右边的 Goal Image 是目标照片。它们给出这次规划的起点视觉信息和目标视觉信息，不是执行前、执行后的实拍对照。

（指右侧坐标图与图例）右侧横轴 X、纵轴 Y 都是平面位置，单位为米。蓝色 GT 是真实参考轨迹；红色 1、黄色 2、绿色 0 是三个候选。路线上的圆点表示离散的轨迹位置，不是障碍物，也不是误差范围。

（沿彩色路线从下往上指）几条候选在图底部先沿横向展开，然后大致沿纵向推进，体现了先左右、再向前的要求。论文通过将前几个时间步的前向动作分量置零，构造符合这种顺序的候选，再优化剩余部分。不同候选的左右位移和前进距离可以不同。

（指终点旁的数字）零点四二二、零点四三九、零点四四一是候选的评价代价，不是坐标值或到目标的距离。绿色候选 0 的代价最低，因此优先选择。虽然蓝色 GT 可以帮助我们观察结果，但选路用的是目标图像的预测评价，不是直接拿真实轨迹当搜索答案。

这个实验展示的是：在模型训练完成以后，通过改变允许的动作，仍可以评价并选择符合指定运动顺序的路线。图里的左右移动也不要直接改称底盘的原地转向，它们是不同的动作含义。
