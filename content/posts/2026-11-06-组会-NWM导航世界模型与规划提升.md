## 1. 从直接生成路线，到预测后再选择

**NWM（Navigation World Models，导航世界模型）组会汇报｜第 1 / 5 页｜约 1 分钟**

> **核心结论：先预测不同走法会看到什么，再判断哪条路线更接近目标。**

正文按 5 页组织，共使用 6 张论文图表。每页围绕图中的一个问题展开，下方口述稿包含指图顺序、可直接讲述的解释，以及模块和符号的备讲表，便于后续移入 PPT 的演讲者备注。

### 先看一个直观例子

![NWM 在相同起点下预测两种走法的未来画面，并与右侧目标照片比较](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2026/11/05/1793861470215-34018627.webp)

**这张图看三处：**

- **左侧：** 同一个起点，黄色线条表示不同的候选走法。
- **中间：** 模型沿着每种走法，连续生成未来画面。
- **右侧：** 把预测末帧与目标照片比较，评价这条路线。

GNM（General Navigation Model，通用导航模型）和 NoMaD（目标掩码扩散策略）主要根据当前观测与目标生成路线；NWM 增加了**预测动作后果、再评价路线**的环节。NoMaD 也能采样多种路线，NWM 可以进一步帮它筛选。

图片来源：[论文 Figure 1(b)：通过生成视频评价导航路线](https://arxiv.org/html/2412.03572v2#S1.F1)，仅提取原图的路线评价部分。新增图片通过 MD Image Uploader 上传。

#### 现场讲述

上次主要介绍了世界模型是什么，这次看它怎样参与导航。先从这张图开始，按从左到右的顺序读。

（指左侧两张 Input）上下两行从相同的观测出发，黄色线条表示两种不同的候选走法。这里输入模型的是画面和动作，黄色线只是为了把动作路线直观地画出来。

（指中间两行画面）每一行是在对应动作下连续预测的未来。标着 `gen.` 的都是模型生成的画面，不是机器人已经走过去以后拍到的照片；从左往右是后续预测时刻。两行的结果不同，是因为它们使用了不同的动作序列。

（指右侧 Goal 和两个 Score）右侧垃圾桶的照片是目标。把每条路线最后预测的画面与这张目标照片比较，就可以给两种走法评分。上下两个 Score 框分别对应上下两条路线；这一张示意图只画了评分入口，没有给出具体分数，第三页会展示真实的评分数字。

所以，这张图展示了“输入候选动作、生成未来、与目标比较”的完整关系。GNM、NoMaD 主要负责生成路线，NWM 则可以用预测结果帮助评价这些路线。

## 2. NWM 如何预测机器人眼前的未来？

**第 2 / 5 页｜约 2 分钟**

> **核心结论：VAE 负责压缩和还原画面，CDiT 负责结合动作预测未来。**

### 用论文结构图解释三个环节

![CDiT 结构：待预测帧读取历史画面，并结合动作和时间信息生成未来表示](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2026/11/05/1793858378771-4bba5d27.webp)

**先用这一行理解整套流程：**

**当前画面 → VAE 压缩 → CDiT + 动作 + 时间间隔 → VAE 还原 → 未来画面。**

这张原图只展开了中间的 **CDiT**，没有把整个 VAE 编码、解码流程都画出来。页面先标出三个读图入口，完整模块解释见下方口述稿：

1. **底部 Future State：** 模型从带噪声的未来表示开始，逐步得到预测结果。
2. **右侧 Context States：** 过去的画面为预测提供参考。
3. **右下方 Conditioning：** 动作和时间信息告诉模型“怎么走、预测多久以后”。

VAE（Variational Autoencoder，变分自编码器）让图像变成便于计算的内部表示；CDiT（Conditional Diffusion Transformer，条件扩散变换器）学习动作对应的视觉变化。**目标照片由规划器用于评价，并不是单步未来预测器必须接收的输入。**

图片来源：[论文 Figure 2：CDiT Block](https://arxiv.org/html/2412.03572v2#S3.F2)。本页 PPT 建议把原图放右侧，左侧只保留流程和三个读图位置，模块和符号的逐项解释保留在下方口述稿中。

<details>
<summary><strong>逐图口述稿｜图 2：沿箭头读懂 CDiT 的输入、模块与输出（约 2 分钟）</strong></summary>

#### 现场讲述

这张图是 CDiT 的一个计算块，主干从底部往顶部走。VAE 的编码器和解码器没有画在这张图里：历史图像先被 VAE 编成内部表示，预测完成以后，再由解码器还原成图像。

（指底部 Future State）底部是要预测的未来表示，记作 `s_{τ+1}`。这是扩散模型：训练时给真实未来表示加噪声，让模型学习恢复；生成时从噪声开始预测，所以并不需要提前知道真实未来。

（沿主干指橙色 Self-Attention）第一个主要模块是自注意力。它让待预测帧内部的不同图像块交换信息，协调同一幅未来画面的内容。这里的自注意力只处理当前待预测帧，不把所有历史帧都放进去两两计算。

（指右侧 Context States，再指粉色 Cross-Attention）历史画面通过交叉注意力进入。可以理解成：当前帧提出查询，去历史画面中查找相关信息。图中虚线 `K,V` 就是历史帧提供的参考内容。这样，模型可以利用之前见过的场景来约束未来预测。

（指绿色 Pointwise Feedforward）上面的前馈网络继续处理每个图像块的特征。旁边的回绕箭头和加号表示把处理前的信息与新结果相加，保留原有信息并逐步更新。

（指右下方 Conditioning → Embedding → AdaLN）另一路输入是动作和时间条件。平面位移、朝向变化、预测时间间隔，以及扩散去噪步先变成向量，再产生图中的缩放、偏移等系数，调节主干的计算。因此，同一张起始画面输入不同动作，能够得到不同预测。

图上 `×N` 表示这样的块堆叠多层，并不表示一次生成 N 帧。完成一帧预测后，再结合下一个动作调用模型，才形成前一页看到的连续未来画面。

#### 图中模块与符号备讲

| 标注 | 通俗解释与对应关系 |
|---|---|
| `Future State s_{τ+1}` | 待预测的未来图像表示；主干围绕它进行去噪处理 |
| `Context States` | 当前及历史观测经过编码后的表示，不是目标照片 |
| `Multi-Head Self-Attention` | 多头自注意力：在当前待预测帧内部交换信息 |
| `Multi-Head Cross-Attention` | 多头交叉注意力：当前帧读取历史帧的信息 |
| `K,V` | Key / Value（键 / 值），来自历史表示；对应的 Query（查询）来自当前预测帧 |
| `Pointwise Feedforward` | 逐位置前馈网络，进一步变换每个 Token（图像块词元）的特征 |
| `Layer Norm` | Layer Normalization（层归一化），调整特征的数值尺度；不负责生成路线 |
| `Scale, Shift` | 根据条件对特征缩放和偏移；图中 `γ、β` 对应这类调节系数 |
| `Scale` 与 `α₁、α₂、α₃` | 调节各处理分支输出的幅度，然后通过加号与主干信息合并 |
| `Embedding` | 把动作及时间等数值编码成网络可使用的向量 |
| `AdaLN` | Adaptive Layer Normalization（自适应层归一化），根据条件产生用于调节主干的系数 |
| `u、φ` | 平面位移与偏航变化，描述怎样移动、怎样改变朝向 |
| `k` 与 `t` | `k` 是物理时间偏移，`t` 是扩散去噪步；它们不是同一个时间量 |
| 回绕箭头与 `+` | Residual Connection（残差连接），把分支结果加回主干 |
| `CDiT Block ×N` | 多个计算块堆叠形成网络深度；与生成帧数、扩散去噪步数都不同 |

**与第四页的联系：** 由于历史帧主要通过交叉注意力被读取，模型避免了把全部历史词元一起做全局自注意力。这是论文比较计算效率时的重要结构原因。

</details>

## 3. 预测结果怎样用于选路？

**第 3 / 5 页｜约 1 分 30 秒**

> **核心结论：比较候选路线的预测末帧，选择与目标照片差异更小的路线。**

### 三条候选路线的实际评分

![NWM 分别预测 P1、P2、P3 的末帧，P3 与目标的 LPIPS 距离最小](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2026/11/05/1793858381169-86c7bf69.webp)

**读图顺序：观测与目标 → 中间的三条路线 → 右侧的预测画面与分数。**

- 先生成候选路线，再用模型连续预测，称为 Rollout（滚动预测）。
- LPIPS（学习式感知图像块相似度）衡量画面特征的差异，**越低越好**。
- 图中 P1 = 0.484、P2 = 0.508、P3 = 0.369，因此选择 **P3**。

候选路线既可以由 NoMaD 提供，也可以通过 CEM（Cross-Entropy Method，交叉熵方法）采样搜索。论文把预测与优化放在 MPC（Model Predictive Control，模型预测控制）框架下；报告的短时独立规划实验只运行了一轮优化。

图片来源：[论文 Figure 7：外部策略路线排序](https://arxiv.org/html/2412.03572v2#S4.F7)。上述三个分数是单个示例，整体性能看下一页的实验数据。

<details>
<summary><strong>逐图口述稿｜图 7：把轨迹、预测画面和 LPIPS 分数一一对应（约 1 分 30 秒）</strong></summary>

#### 现场讲述

这一张可以看成第一页评分示意的具体版本。先从左侧读：Observation 是当前观测，Goal 是目标图像，它们是本次选路的已知条件。

（指中间轨迹图）中间的 P1、P2、P3 是三条候选路线，对应橙、红、绿三种颜色。横纵轴是平面位置，标注单位为米；蓝色 Goal 表示目标参考，不是第四条候选。曲线表示不同的移动方式，颜色只是帮助我们把路线和右侧结果对应起来。

（逐一指右侧 Prediction 1、2、3）右侧每张图都是模型沿对应候选路线预测的最后一张画面。P1 对应 Prediction 1，P2 对应 Prediction 2，P3 对应 Prediction 3。这里是在比较三条路线各自的终点预测，不是把右侧三张图按顺序接成一段视频。

（指三个 Loss）每张预测末帧都与左侧同一张 Goal 图像计算 LPIPS。它比较图像特征的差异，而不是直接计算路线终点的几何距离。P1 是零点四八四，P2 是零点五零八，P3 是零点三六九，所以选择 P3。绿色框里的 Min 指感知代价最小，不代表成功率，也不代表零误差。

这一图展示的是外部策略排序：NoMaD 提供候选，NWM 预测和评分。模型选择时使用目标图像，不需要真实未来轨迹；真实轨迹是在后面的离线实验中用于检验结果。

#### 图中标注备讲

| 标注 | 应怎样解释 |
|---|---|
| `Observation` | 当前看到的画面 |
| `Goal` | 希望到达位置对应的目标图像 |
| `P1 / P2 / P3` | 三条不同的候选路线，与右侧同编号预测一一对应 |
| `X(m)、Y(m)` | 路线在平面中的位置坐标；不要把这个单位套到第四页未标单位的误差表上 |
| `Prediction 1 / 2 / 3` | 每条候选路线各自的末帧预测 |
| `Loss` | 预测末帧与目标图像的 LPIPS 距离，越小越好 |
| `P3 (Min)`、绿色框 | 以该代价选出的候选，不是额外的一种规划算法 |

**若被问“为什么不直接挑几何上最近的？”：** 本文此处采用视觉目标评价。中间的路线图帮助人理解运动结果，右侧图像与目标的感知差异才是这个例子的评分依据。

</details>

## 4. 相比已有方法，具体提升在哪里？

**第 4 / 5 页｜约 2 分 30 秒｜汇报重点**

> **核心结论：一方面降低短时轨迹误差，另一方面减少未来预测模型的计算量。**

### 图表一：路线误差是否下降？

![论文 Table 2：GNM、NoMaD、NWM 辅助排序与独立规划的 ATE 和 RPE 对比](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2026/11/05/1793861471528-6ac0fe43.webp)

**看 NoMaD 与最后一行：**

- ATE（Absolute Trajectory Error，绝对轨迹误差）：**1.93 → 1.13，下降约 41.5%**。
- RPE（Relative Pose Error，相对位姿误差）：**0.52 → 0.35，下降约 32.7%**。
- 中间两行说明：让 NWM 给 NoMaD 的候选路线排序，也能降低误差。

实验范围是 **RECON 已知环境、2 秒离线轨迹评估**；降幅由表中均值计算，不等于实机成功率提高相同比例。

图片来源：[论文 Table 2](https://arxiv.org/html/2412.03572v2#S4.T2)。新增图片通过 MD Image Uploader 上传，保留原表均值与标准差。

### 图表二：预测模型是否更省计算？

![CDiT 与标准 DiT 的预测误差及运算量对比，越靠左下越好](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2026/11/05/1793858382111-850a1bd1.webp)

**读图只看两个方向：向左，计算量更少；向下，预测误差更低。**

横轴是 TFLOPs（万亿次浮点运算），纵轴是 LPIPS，圆大小表示参数量。论文报告可比参数规模下，CDiT 约使用标准 DiT **四分之一的 FLOPs**，同时预测效果更好。这是模型计算量对比。

图片来源：[论文 Figure 5](https://arxiv.org/html/2412.03572v2#S4.F5)。PPT 本页建议左右两栏：左侧放误差表和降幅，右侧放效率图；只保留两条主要结论。

<details>
<summary><strong>逐图口述稿｜表 2 与图 5：每一行、每个坐标和气泡怎样读（约 2 分 30 秒）</strong></summary>

#### 现场讲述：先读导航误差表

这一页有两类证据，先读导航结果，再看预测模型的计算效率。

（指表头）表格评估的是 RECON 已知环境里的两秒轨迹。ATE 衡量整条轨迹与真实轨迹的偏差，RPE 衡量相邻位姿变化的误差，两个向下箭头都表示越小越好。数值写成均值加减标准差，表示重复评估的平均水平和波动，不是一次实验的最大值与最小值。

（从上往下指五行）第一行 GNM 是已有导航策略；第二行 NoMaD 也是策略基线。第三、四行都保留 NoMaD 生成路线，分别生成十六条和三十二条候选，再让 NWM 筛选；这里的“乘十六、乘三十二”指候选数量。最后一行才是 NWM 自己搜索路线，不依赖 NoMaD 提供候选。

（指 NoMaD 与最后一行）ATE 从一点九三降到一点一三，RPE 从零点五二降到零点三五，按均值计算下降约百分之四十一点五和百分之三十二点七。再看两行排序结果，也比 NoMaD 的误差低，说明它还可以辅助已有策略。这里比较的是轨迹误差，不能换算成实机成功率。

#### 现场讲述：再读计算效率气泡图

（指横纵轴和图例）横轴是 TFLOPs，也就是运算量，越靠左越省计算；纵轴是 LPIPS，越靠下表示未来图像预测误差越小。注意，这里的 LPIPS 是预测图像与真实未来图像比较，和第三页拿预测末帧与目标照片做比较，是不同的实验用途。

蓝色圆代表 CDiT，红色圆代表标准 DiT；每个圆是一种模型配置。圆大小表示参数量，S、B、L、XL 表示各自系列中从小到大的模型，不同架构的同名档位不能直接当作参数量完全相同。

（指蓝色 CDiT-L 与红色 DiT-XL）这两个圆大小接近，可以观察相近参数规模的对比：蓝色圆更靠左，也更靠下，说明计算量更少，同时预测误差更低。论文报告的约四倍 FLOPs 优势，就是在这样的可比规模下讨论的，不能理解成每种配置、每块硬件或整套导航都快四倍。

#### 表格与气泡图标注备讲

| 项目 | 含义与容易混淆的地方 |
|---|---|
| `model` | 比较的方法或系统组合 |
| `GNM` | 直接生成轨迹的导航策略基线 |
| `NoMaD` | 用扩散策略生成候选轨迹的基线 |
| `NWM + NoMaD (×16 / ×32)` | NWM 从 NoMaD 的 16 / 32 条候选中评分、选择；不是模型参数扩大 16 / 32 倍 |
| `NWM (planning)` | 用 NWM 预测结果配合搜索，进行独立规划 |
| `±` | 原表报告的标准差，不是置信区间；`±0.00` 只表示四舍五入后显示为零 |
| 图 5 的评估任务 | RECON 上向未来 4 秒的单步图像预测；与表 2 的 2 秒轨迹评估不同 |
| 蓝色 / 红色 | CDiT / DiT 两个模型系列 |
| `TFLOPs` | 万亿次浮点运算量；横轴不是实际测量的秒数 |
| `LPIPS` | 此图衡量预测与真实未来图像的差异；纵轴不是导航成功率 |
| `Diameter #Params(M)` | 圆直径用于示意参数规模；M 表示百万参数；圆越大不表示效果一定越好 |
| 圆的位置 | 越靠左下，意味着在这个任务里运算更少、预测误差更低 |

## 5. NWM 怎样按指定要求规划路线？

**第 5 / 5 页｜约 1 分 30 秒**

> **核心结论：限制候选路线中的部分动作，再让模型评价符合要求的走法。**

### 约束实验：先向左或右运动，再向前

![NWM 在先向左或右运动再向前的约束下评价多条候选路线，绿色候选 0 代价最低](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2026/11/05/1793858383010-77497c7a.webp)

**这张图看三处：**

- **左侧两张图：** 当前观测与目标照片。
- **右侧曲线：** 蓝色 GT（Ground Truth，真实参考轨迹），以及红、黄、绿三条候选路线。
- **绿色候选 0：** 在图示候选中代价最低，被优先选择。

论文通过把指定时间步的部分动作分量设为零，构造符合要求的候选。例如 `left-right first` 在前 3 步禁止前向运动，再优化剩余部分。图中的左右运动不应直接理解为差速机器人的原地转向。

这个实验展示的是：**训练完成后，可以在规划时加入新的动作顺序要求，无需为每种要求重训策略。** 这里验证的是指定动作约束下的规划能力。

图片来源：[论文 Figure 9](https://arxiv.org/html/2412.03572v2#S4.F9)；实验设置见[正文 §4.4 与 Table 3](https://arxiv.org/html/2412.03572v2#S4.T3)。

#### 现场讲述

这一页看一个具体的动作约束实验：除了接近目标，还要求路线先向左或右运动，再向前。

（指两张照片）左边的 Condition Image 是当前观测，右边的 Goal Image 是目标照片。它们给出这次规划的起点视觉信息和目标视觉信息，不是执行前、执行后的实拍对照。

（指右侧坐标图与图例）右侧横轴 X、纵轴 Y 都是平面位置，单位为米。蓝色 GT 是真实参考轨迹；红色 1、黄色 2、绿色 0 是三个候选。路线上的圆点表示离散的轨迹位置，不是障碍物，也不是误差范围。

（沿彩色路线从下往上指）几条候选在图底部先沿横向展开，然后大致沿纵向推进，体现了先左右、再向前的要求。论文通过将前几个时间步的前向动作分量置零，构造符合这种顺序的候选，再优化剩余部分。不同候选的左右位移和前进距离可以不同。

（指终点旁的数字）零点四二二、零点四三九、零点四四一是候选的评价代价，不是坐标值或到目标的距离。绿色候选 0 的代价最低，因此优先选择。虽然蓝色 GT 可以帮助我们观察结果，但选路用的是目标图像的预测评价，不是直接拿真实轨迹当搜索答案。

这个实验展示的是：在模型训练完成以后，通过改变允许的动作，仍可以评价并选择符合指定运动顺序的路线。图里的左右移动也不要直接改称底盘的原地转向，它们是不同的动作含义。

### 使用说明

正文的五个二级标题分别对应一页 PPT，建议主讲时长约 9 分钟，符号备讲表用于理解和问答，不逐项朗读。制作幻灯片时只取“核心结论”“页面要点”和图表；“逐图口述稿”放入演讲者备注，来源放页脚。不要把讲述稿和这份备查资料一起铺到幻灯片上。

### 完整模型结构与计算效率

默认模型使用预训练 Stable Diffusion VAE（稳定扩散变分自编码器）、4 帧上下文及约十亿参数的 CDiT-XL。训练中每个上下文抽取 4 个目标状态，这不表示一次导航要同时到达 4 个目标。

CDiT 在待预测帧内部做 Self-Attention（自注意力），通过 Cross-Attention（交叉注意力）读取历史帧，并通过 AdaLN（自适应层归一化）注入动作、物理时间间隔和扩散去噪步。物理时间间隔与去噪步是不同概念。

完整结构图见正文第 2 节。来源：[Figure 2](https://arxiv.org/html/2412.03572v2#S3.F2)。

效率图见正文第 4 节。来源：[Figure 5](https://arxiv.org/html/2412.03572v2#S4.F5)。横轴为 TFLOPs（万亿次浮点运算），纵轴为 LPIPS，越靠左下越好，圆的大小表示参数量。

### 独立规划与评价的具体设置

- 无约束独立规划优化终点的 `(Δx, Δy, Δyaw)` 三个变量，再转换成 8 个均匀位移增量，末步施加偏航变化。
- 每步 0.25 秒，共 2 秒；采样 120 个候选，每个候选重复预测 3 次取平均评分；报告实验只进行 1 轮优化。
- 目标可概括为“预测末帧与目标的感知距离 + 无效动作惩罚 + 不安全状态惩罚”，并考虑预测随机性。安全状态集合是公式预留的接口，指定动作顺序实验没有验证完整几何安全模块。
- CEM 与 MPC 的完整名称分别为 Cross-Entropy Method（交叉熵方法）、Model Predictive Control（模型预测控制）。前者是优化方法，后者是预测与控制框架。

来源：[正文 §3.3、§4.4](https://arxiv.org/html/2412.03572v2#S3.SS3)、[附录 §7](https://arxiv.org/html/2412.03572v2#S7)。

### 完整导航实验数据

正文第 4 页的原表图片取自 CVPR 正文 Table 2，完整数据如下。保留原表尺度，不额外标成“米”。ATE 的英文为 Absolute Trajectory Error，RPE 的英文为 Relative Pose Error。

| 方法 | ATE ↓ | RPE ↓ |
|---|---|---|
| GNM | 1.87 ± 0.00 | 0.73 ± 0.00 |
| NoMaD | 1.93 ± 0.04 | 0.52 ± 0.00 |
| NWM + NoMaD（16 条候选） | 1.83 ± 0.03 | 0.50 ± 0.01 |
| NWM + NoMaD（32 条候选） | 1.78 ± 0.03 | 0.48 ± 0.01 |
| NWM（独立规划） | 1.13 ± 0.02 | 0.35 ± 0.01 |

来源：[Table 2](https://arxiv.org/html/2412.03572v2#S4.T2)。相对 NoMaD，独立规划 ATE 的降幅为 `(1.93−1.13)/1.93 ≈ 41.5%`，RPE 降幅为 `(0.52−0.35)/0.52 ≈ 32.7%`；32 条候选排序的 ATE 降幅约为 7.8%。这些是均值相对变化，不是显著性检验，也不是成功率变化。

机器人训练数据来自 RECON、SCAND、TartanDrive、HuRoN。动作由位姿变化推得，滤除后退片段，并按机器人平均步长归一化。GO Stanford 用于未知环境评估，Ego4D 用于额外无标签训练。

导航评估为每个数据集选择 100 个最难被“始终前进”启发式预测的样本；4 秒未来图像预测评估则随机选取 500 个测试样本，两者不是同一评估口径。论文描述模型采样 5 次报告均值和标准差，`±0.00` 是显示精度下的结果。[来源：正文 §4.1 与附录 §8.1](https://arxiv.org/html/2412.03572v2#S8.SS1)

### 生成质量与未知环境预测

- **生成质量：** RECON 上按真实动作生成 16 秒、4 FPS（每秒帧数）的视频，NWM 的 FVD（Fréchet Video Distance，弗雷歇视频距离）为 **200.969 ± 5.629**，DIAMOND 为 **762.734 ± 3.361**。视频更接近真实数据分布，不直接等于避障更安全。[Figure 6](https://arxiv.org/html/2412.03572v2#S4.F6)
- **泛化：** 加入 Ego4D 后，4 秒未来预测的 GO Stanford LPIPS 从 **0.658 ± 0.002** 降至 **0.652 ± 0.003**；但 RECON 从 **0.295 ± 0.002** 升至 **0.368 ± 0.003**。只能说在该未知环境上有小幅预测收益，不能说所有环境全面提升。[Table 4](https://arxiv.org/html/2412.03572v2#S4.T4)


### 原文核对 1：主表与附录不能混用

正文 Table 2 与 arXiv v2 附录 Table 7 的部分 RECON 均值并不完全一致，例如 NoMaD ATE 分别为 1.93 和 1.95，32 条候选排序分别为 1.78 和 1.79。原文未在表旁说明差异原因，本稿不推测原因；本稿数字与降幅统一采用 **Table 2**。

附录 Table 7 的列名写作 `RTE`，表注却写 ATE / RPE；本稿主表使用正文 Table 2 的 **RPE**，不擅自修正整张附录表。

也不能概括成“NWM 独立规划在所有数据集、所有指标上都最好”：附录 HuRoN 上，其 ATE 为 **4.12 ± 0.03**，NoMaD 为 **3.73 ± 0.04**，NWM + NoMaD（32 条候选）为 **3.68 ± 0.03**。[来源：附录 Table 7](https://arxiv.org/html/2412.03572v2#S8.T7)

### 原文核对 2：“约 4 倍效率”指什么？

原文结合 FLOPs 对比讨论效率，图 5 横轴也是 FLOPs。对上下文帧数的线性 / 二次复杂度比较，默认每帧 Token 数与维度固定；不能理解成整个网络对所有输入规模都只有线性复杂度，也不能换算成任意 GPU 上的端到端 4 倍加速。

### 原文核对 3：约束名称与实现应怎样解释？

正文对 `forward first` 使用“先前进 5 步、再转 3 步”的概括，附录 §7 的具体示例则将平移分量设为前 5 步 `u=(Δx,0)`、后 3 步 `u=(0,Δy)`。因此本稿保留原始实验名称，强调**动作分量掩码与运动顺序**，不把它们改写成三种通用转向或避障规则。

Table 3 的数值是相对于无约束规划的终点位置与偏航误差变化，带有正负号，不是成功率或碰撞率。[来源：Table 3 与附录 §7](https://arxiv.org/html/2412.03572v2#S4.T3)

### 原文核对 4：论文有没有实时性证据？

有加速分析，但需要读清口径。附录 Table 8 报告 NVIDIA RTX 6000 Ada 上模拟单条轨迹的时间：原始 **30.3 ± 0.2 秒**，Time Skip（时间跳步）后 **14.7 ± 0.1 秒**，再加 Distillation（蒸馏）后 **0.4 ± 0.1 秒**。表中的四位量化 **0.1 秒是估计值，作者明确尚未探索量化**。

这部分讨论以排序 32 条、每条 4 秒轨迹为应用背景，但时间分析针对**单条轨迹模拟**；不要把 0.4 秒直接作为全部候选、感知与控制均包含在内的整机规划延迟。[来源：附录 Table 8 及上下文](https://arxiv.org/html/2412.03572v2#S8.T8)

### 原文核对 5：训练与预测实验的补充设置

- 默认使用 Stable Diffusion VAE（稳定扩散变分自编码器），4 帧上下文、每个上下文抽取 4 个目标状态训练；这里的 4 个目标是训练采样，不是一次导航必须同时到达 4 个目标。
- 机器人数据滤除后退运动，并按平均步长归一化动作。用于差速机器人时，需要核对坐标系、尺度与运动可执行性。
- 4 秒预测质量评估每个数据集随机选取 500 个测试样本，与导航评估的 100 个样本口径不同。
- 论文描述模型采样 5 次报告均值及标准差；主表的 `±0.00` 是显示精度下的数值，不表示误差严格为零。
- 官方公开权重的说明提到，训练图像进行人脸模糊处理后重新训练，复现结果可能与论文不同，不能假定当前下载权重必然精确复现表值。

来源：[正文 §4.1](https://arxiv.org/html/2412.03572v2#S4.SS1)、[附录 §8.1](https://arxiv.org/html/2412.03572v2#S8.SS1)、[官方模型说明](https://huggingface.co/facebook/nwm/blob/main/README.md)。
