## Launch与包依赖配置

修改launch重定向到咱们的模型，主要先看下面的launch：

- `pb2025_nav_bringup`里的`rm_navigation_reality_launch.py`
  - 同功能包下的`robot_state_publisher_launch.py`


- `rmu_gazebo_simulator`里的`bringup_sim.launch.py`
  - 同功能包下的`spawn_robots.launch.py`
  - 同功能包下的`package.xml`

- `robot_description`里的`robot_description_launch.py`
  


### robot_state_publisher_launch.py（机器人关节TF发布入口）

```python
    pkg_pb2025_robot_description_dir = get_package_share_directory(
        "pb2025_robot_description"
    )

    declare_robot_name_cmd = DeclareLaunchArgument(
        "robot_name",
        default_value="pb2025_sentry_robot",
        description="The file name of the robot xmacro to be used",
    )
```

改成

```python
    pkg_robot_description_dir = get_package_share_directory(
        "robot_description"
    )

    declare_robot_name_cmd = DeclareLaunchArgument(
        "robot_name",
        default_value="reality_robot",
        description="The file name of the robot xmacro to be used",
    )
```


### spawn_robots.launch.py（生成仿真机器人）

```python
    pkg_pb2025_robot_description = get_package_share_directory(
        "pb2025_robot_description"
    )

    robot_xmacro_path = os.path.join(
        pkg_pb2025_robot_description,
        "resource",
        "xmacro",
        "simulation_robot.sdf.xmacro",
    )
```

改成：

```python
    pkg_robot_description = get_package_share_directory(
        "robot_description"
    )

    robot_xmacro_path = os.path.join(
        pkg_robot_description,
        "resource",
        "xmacro",
        "simulation_robot.sdf.xmacro",
    )
```

### robot_description_launch.py（机器人模型加载入口）

```python
def generate_launch_description():
    # Get the launch directory
    bringup_dir = get_package_share_directory("pb2025_robot_description")
```

改成

```python
def generate_launch_description():
    # Get the launch directory
    bringup_dir = get_package_share_directory("robot_description")
```

### pb2025_nav_bringup里的package.xml（导航启动包依赖）

这个包的 `robot_state_publisher_launch.py` 会加载 `robot_description`，因此补上运行依赖：

```xml
<exec_depend>robot_description</exec_depend>
```

`robot_state_publisher_launch.py` 的默认入口为 `reality_robot`；描述包自身的 `robot_description_launch.py` 默认仍为 `simulation_robot`。Gazebo 的 `spawn_robots.launch.py` 继续加载 `simulation_robot.sdf.xmacro`。

### rmu_gazebo_simulator里的package.xml（仿真包依赖）

```xml
<depend>pb2025_robot_description</depend>
```

改成

```xml
<depend>robot_description</depend>
```
