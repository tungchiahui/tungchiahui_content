### 环境说明

本教程同时适用于 Windows 和 Linux。Windows 使用 PowerShell，Linux 使用 Bash；文件编辑统一使用 VS Code。

### Linux

#### 安装Git

以下命令适用于 Ubuntu、Debian 及其衍生发行版，其他发行版请使用对应的包管理器安装 Git。

```bash
sudo apt-get update
sudo apt-get install git
git --version
```

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/image2.webp)

### Windows

#### 安装Git

详看[MSYS2配置环境教程](/wiki/2023-10-05-cplusplus-jiao-xue/0100-0200-windows-kai-fa-huan-jing-da-jian-yu-ce-shi#%E5%AE%89%E8%A3%85-msys2)，完成 Git 安装和 PATH 配置后，重新打开 PowerShell，确认可以执行：

```powershell

```

### 两种系统共用：安装和验证VS Code

从 [VS Code官网](https://code.visualstudio.com/) 下载适合自己系统的版本并安装。

Windows 安装时启用“添加到 PATH”（Add to PATH）选项。Linux 按官网提供的对应发行版安装方式操作。

安装完成后，重新打开终端并执行：

```text
git --version
code --version
```

两条命令都能输出版本信息后，即可进入后面的实操。

如果提示找不到 `code`，请检查 VS Code 的安装和 PATH 配置，再重新打开终端。也可以先从桌面打开 VS Code，通过“文件 → 打开文件夹”进入练习目录，并在编辑器中创建和编辑文件。

### Windows下配置VS Code的Git路径

如果 VS Code 已经能自动识别 Git，可以跳过本节。

如果无法识别，按 `Ctrl+Shift+P` 打开命令面板，搜索并选择 `Preferences: Open User Settings (JSON)`：

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1793176249160-f7307fb5.webp)

在设置 JSON 对象中加入以下属性；如果前面已有其他属性，注意用逗号分隔：

```json
"git.path": "C:/msys64/ucrt64/bin/git.exe"
```

这里的路径对应 MSYS2 安装在 `C:/msys64`、使用 UCRT64 Git 的情况，请按实际的 `git.exe` 位置填写。

![](https://cdn.tungchiahui.cn/tungwebsite/assets/images/2023/12/29/1793176175789-46f94599.webp)

保存后重启 VS Code。`git.path` 只决定 VS Code 使用哪个 Git，不会修改 PowerShell 的 PATH；终端中的 `git --version` 仍需能够正常执行。
