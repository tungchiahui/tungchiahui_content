> 本节自己创建一个物理底盘模型，显式使用反馈计算里程计。沿用第 1400 篇的 Fortress 启动文件。

## 示例 1：编写完整底盘模型

保存为 `urdf/diff_gz.urdf.xacro`：

```xml
<?xml version="1.0"?>
<robot name="learning_diffbot" xmlns:xacro="http://www.ros.org/wiki/xacro">
  <link name="base_link">
    <inertial><mass value="2"/><inertia ixx="0.02" ixy="0" ixz="0" iyy="0.03" iyz="0" izz="0.04"/></inertial>
    <visual><geometry><box size="0.3 0.2 0.08"/></geometry></visual>
    <collision><geometry><box size="0.3 0.2 0.08"/></geometry></collision>
  </link>

  <link name="left_wheel">
    <inertial><mass value="0.2"/><inertia ixx="0.00014" ixy="0" ixz="0" iyy="0.00025" iyz="0" izz="0.00014"/></inertial>
    <visual><origin rpy="1.57079632679 0 0"/><geometry><cylinder radius="0.05" length="0.03"/></geometry></visual>
    <collision><origin rpy="1.57079632679 0 0"/><geometry><cylinder radius="0.05" length="0.03"/></geometry></collision>
  </link>
  <joint name="left_wheel_joint" type="continuous">
    <parent link="base_link"/><child link="left_wheel"/>
    <origin xyz="0 0.15 0"/><axis xyz="0 1 0"/>
    <limit effort="5" velocity="20"/>
  </joint>

  <link name="right_wheel">
    <inertial><mass value="0.2"/><inertia ixx="0.00014" ixy="0" ixz="0" iyy="0.00025" iyz="0" izz="0.00014"/></inertial>
    <visual><origin rpy="1.57079632679 0 0"/><geometry><cylinder radius="0.05" length="0.03"/></geometry></visual>
    <collision><origin rpy="1.57079632679 0 0"/><geometry><cylinder radius="0.05" length="0.03"/></geometry></collision>
  </link>
  <joint name="right_wheel_joint" type="continuous">
    <parent link="base_link"/><child link="right_wheel"/>
    <origin xyz="0 -0.15 0"/><axis xyz="0 1 0"/>
    <limit effort="5" velocity="20"/>
  </joint>

  <link name="front_caster">
    <inertial><mass value="0.02"/><inertia ixx="0.0000032" ixy="0" ixz="0" iyy="0.0000032" iyz="0" izz="0.0000032"/></inertial>
    <visual><geometry><sphere radius="0.02"/></geometry></visual>
    <collision><geometry><sphere radius="0.02"/></geometry></collision>
  </link>
  <joint name="front_caster_fixed" type="fixed"><parent link="base_link"/><child link="front_caster"/><origin xyz="0.12 0 -0.03"/></joint>
  <gazebo reference="front_caster"><mu1>0.0</mu1><mu2>0.0</mu2></gazebo>

  <link name="rear_caster">
    <inertial><mass value="0.02"/><inertia ixx="0.0000032" ixy="0" ixz="0" iyy="0.0000032" iyz="0" izz="0.0000032"/></inertial>
    <visual><geometry><sphere radius="0.02"/></geometry></visual>
    <collision><geometry><sphere radius="0.02"/></geometry></collision>
  </link>
  <joint name="rear_caster_fixed" type="fixed"><parent link="base_link"/><child link="rear_caster"/><origin xyz="-0.12 0 -0.03"/></joint>
  <gazebo reference="rear_caster"><mu1>0.0</mu1><mu2>0.0</mu2></gazebo>

  <ros2_control name="DiffSystem" type="system">
    <hardware><plugin>gz_ros2_control/GazeboSimSystem</plugin></hardware>
    <joint name="left_wheel_joint"><command_interface name="velocity"/>
      <state_interface name="position"/><state_interface name="velocity"/>
    </joint>
    <joint name="right_wheel_joint"><command_interface name="velocity"/>
      <state_interface name="position"/><state_interface name="velocity"/>
    </joint>
  </ros2_control>

  <gazebo>
    <plugin filename="gz_ros2_control-system" name="gz_ros2_control::GazeboSimROS2ControlPlugin">
      <parameters>$(find learn_control_hardware)/config/diff_controllers.yaml</parameters>
    </plugin>
  </gazebo>
</robot>
```

### 几何与方向说明

车体 x 轴朝前，左轮在 y=+0.15 m，右轮在 y=-0.15 m，轮半径为 0.05 m。两轮关节轴都沿 +y，因此同号正角速度对应同一前进方向。前后小球提供支撑，并设低摩擦以便转弯。

本模型用于控制与接触入门，参数并非对某台实物的辨识结果。固定关节合并、碰撞和摩擦都会影响仿真，调试时要同时观察车体与轮子。

## 示例 2：编写底盘控制器参数

保存为 `config/diff_controllers.yaml`：

```yaml
controller_manager:
  ros__parameters:
    update_rate: 100
    joint_state_broadcaster:
      type: joint_state_broadcaster/JointStateBroadcaster
    diff_controller:
      type: diff_drive_controller/DiffDriveController
diff_controller:
  ros__parameters:
    left_wheel_names: [left_wheel_joint]
    right_wheel_names: [right_wheel_joint]
    wheel_separation: 0.30
    wheel_radius: 0.05
    position_feedback: true
    open_loop: false
    use_stamped_vel: false
    cmd_vel_timeout: 0.5
    publish_rate: 50.0
    odom_frame_id: odom
    base_frame_id: base_link
    enable_odom_tf: true
    linear.x.has_velocity_limits: true
    linear.x.max_velocity: 0.2
    angular.z.has_velocity_limits: true
    angular.z.max_velocity: 0.5
```

在 package.xml 中补充：

```xml
<exec_depend>diff_drive_controller</exec_depend>
```

### 和上一章不同的地方

本例 `use_stamped_vel: false`，输入 Topic 为 `/diff_controller/cmd_vel_unstamped`，消息类型 Twist；`open_loop: false`，里程计来自轮子反馈。不能沿用上一章的 `/cmd_vel` 和 TwistStamped。

## 编译运行

停止其它机器人后执行：

```bash
cd ~/ros2_control_humble_ws
colcon build --symlink-install --packages-select learn_control_hardware
source install/setup.bash
```

```bash
ros2 launch learn_control_hardware sim.launch.py gui:=false \
  model:=$(ros2 pkg prefix learn_control_hardware)/share/learn_control_hardware/urdf/diff_gz.urdf.xacro \
  controller:=diff_controller
```

终端 2：

```bash
source /opt/ros/humble/setup.bash
source ~/ros2_control_humble_ws/install/setup.bash
```

```bash
ros2 topic pub --rate 10 /diff_controller/cmd_vel_unstamped \
  geometry_msgs/msg/Twist "{linear: {x: 0.08}, angular: {z: 0.0}}"
```

另一个终端观察：

```bash
ros2 topic echo /diff_controller/odom
ros2 topic echo /joint_states
ign topic -l
```

### 本次容器实测结果

Fortress 中两轮位置同步增加，反馈里程计 x 曾采到约 0.3720 m。位置积分结果会随实际执行时长变化。

补充的一次实测中，同一时刻反馈里程计 x 约 0.3664 m，Gazebo 世界中的 learning_robot 模型 x 约 0.3631 m，确认车体确实发生位移。两者不完全相同。

轮子反馈计算的里程计仍不是世界真值：打滑时两轮可以转动而车体位移很小。需要对照 Gazebo 世界坐标中的模型姿态，例如通过 `/world/empty/pose/info` 查找 learning_robot，或者在 GUI 中观察模型位移。

## 示例 3：验证转弯与停止

先按 Ctrl+C 停止直行发布，再发送：

```bash
ros2 topic pub --rate 10 /diff_controller/cmd_vel_unstamped \
  geometry_msgs/msg/Twist "{linear: {x: 0.0}, angular: {z: 0.3}}"
```

停止发布后，cmd_vel_timeout 应让轮速目标归零。显式停车命令是：

```bash
ros2 topic pub --once /diff_controller/cmd_vel_unstamped \
  geometry_msgs/msg/Twist "{linear: {x: 0.0}, angular: {z: 0.0}}"
```

### 本示例需要注意的点

轮子不动时先查控制器与接口；轮子转而车不走时再查接触、摩擦、关节轴和模型是否离地。不要为了让里程计“看着动了”而改成 open_loop 掩盖物理问题。

对应源码：[gz_ros2_control/gz_ros2_control/src/gz_system.cpp](https://github.com/ros-controls/gz_ros2_control/blob/3f341cd49ed579cfb17422582eb14920c203f269/gz_ros2_control/src/gz_system.cpp)、[ros2_controllers/diff_drive_controller/src/odometry.cpp](https://github.com/ros-controls/ros2_controllers/blob/65db73628ebac1948833f0fbdc60973c74d6cd0e/diff_drive_controller/src/odometry.cpp)。
