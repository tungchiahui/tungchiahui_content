> 本套教程面向 ROS 2 Humble、Ubuntu 22.04 与容器 ysu_ros_humble。采用完整实例、运行现象、执行顺序和关键函数解释相结合的方式学习 ros2_control。

## 学习路线

```text
运行官方 RRBot
  → 自己创建工作区与双关节工程
  → 模拟硬件 + RViz
  → 接口、生命周期、控制周期与轨迹
  → Fortress 机械臂与差速底盘物理仿真
  → 自定义控制器与框架源码
  → Asio 虚拟串口与模拟下位机
  → 根据实际设备完成实物适配
```

学习工作区由你跟随文章创建。作者验证使用容器内独立临时目录，没有替你在 ROS_WS 中建立学习工程。

## 开始前需要什么

具备基本 C++ 类、继承、指针与 vector 知识；知道 ROS 2 包、Topic、参数与 launch 的基本用途。遇到 pluginlib、生命周期和 realtime buffer 时，教程会结合当前实例解释。

先不要求真实机器人。到第 2100 篇为止，可以使用容器、仿真和虚拟串口完成主要实践。第 2200 篇以后涉及的真实设备，需要型号、协议和硬件验证条件。

## 工作区与终端约定

| 路径 | 用途 | 由谁创建 |
|---|---|---|
| ~/ros2_control_demos_ws | 官方实例 | 你在第 0100 篇创建 |
| ~/ros2_control_humble_ws | 亲手编写的学习工程 | 你在第 0400 篇开始创建 |
| ~/ros2_control_humble_reference | 固定版本框架源码阅读 | 你按第 0100 篇下载 |

`~` 指容器当前用户主目录，不自动等于宿主机目录。所有构建、安装和运行命令默认在容器中执行，宿主机操作会明确标注。

每个新终端都要 source 系统 Humble 和本次使用的一个工作区。同一 domain 中一次只运行本教程的一个机器人。GUI 需要容器图形环境；作者本次仿真验证采用无界面方式。

## 教程统一写法

每个实践例子解释程序目标、文件位置、完整必要代码、编译运行、输出与执行顺序、函数参数与返回值、常见问题及源码入口。

自编 ROS 回调优先用 std::bind。官方源码保留原写法。代码以 C++17 为基础，使用容器 GCC 11 支持的功能。实际数据、预期现象和教学伪代码会分别说明。

## 各类运动环境

| 环境 | 反馈来自哪里 | 能验证什么 |
|---|---|---|
| 模拟硬件 + RViz | C++ 内部教学模型 | 框架、接口、数据与显示链路 |
| Gazebo Fortress | 仿真关节与物理引擎 | 模型、仿真后端、控制与反馈 |
| 虚拟串口 | 模拟下位机 | 收发、协议解析、线程交接与超时 |
| 实物 | 编码器、驱动器和传感器 | 设备行为、单位、模式、故障与停止 |

RViz 显示运动不是物理仿真；轮子里程计不是世界位姿真值；虚拟串口成功不是实物已经验证。

## 作者验证记录

作者临时源码与构建目录位于容器内 `/tmp/ros2_control_humble_authoring`。它不属于学习步骤所需路径，容器清理临时目录后可按文章重新构建。

| 项目 | 本次结果与边界 |
|---|---|
| 文档代码复建 | 从文章提取两个自编包的完整代码，在独立目录重新构建成功 |
| GenericSystem 与生命周期 | 初期镜像硬件运行、控制器与硬件停用/激活命令验证通过 |
| 官方 demos | example_1、2、3、9 及所需本地依赖构建成功 |
| 官方 RRBot | 启动、接口与位置反馈验证；缓慢响应符合固定模拟参数 |
| 官方 DiffBot | 带时间戳命令、轮子状态与命令积分里程计验证 |
| 自编 MiniSystem | 编译、插件加载、接口导出与位置收敛通过 |
| 轨迹控制器 | Action 返回 error_code 0、SUCCEEDED |
| 自编 HoldController | 接口切换与位置目标通过；非法 NaN 目标被拒绝 |
| Fortress 双关节 | 无界面加载和关节反馈通过，目标约 [0.3, -0.2] |
| Fortress 差速底盘 | 无界面加载、轮子反馈与反馈里程计通过；另一次对照世界位姿确认车体移动 |
| 虚拟串口后端 | 反馈收敛至约 [0.25, -0.15]；停止下位机后进入错误处理 |
| 真实硬件 | 尚无设备型号与协议，提供适配流程和换算实例，未作实物验证 |
| GUI 与全部进阶实例 | 未逐一执行，文中不把它们标为实测通过 |

采样值用于说明本次运行，不是跨机器精确复现的时间基准。使用关节名称匹配反馈，按误差与状态验收。
